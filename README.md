# 清醒消费（wallet）

一个自用的手机记账网页，可以「添加到主屏幕」当 App 用。
纯前端：没有服务器、没有账号，所有数据只存在手机浏览器里（localStorage），记得定期在「我的 → 备份与清理」导出备份。

线上地址（GitHub Pages）：https://123sdgv.github.io/wallet/

## 功能

- **首页**：总资产 / 当前可安排 / 安全余额 / 专项储蓄，本月预算还能花多少，消费计划
- **记一笔**：支出、收入、退款、转账（账户之间挪钱，不算收支）；也可以先建「消费计划」，买了再一键入账
- **预算外**：记账、编辑流水、消费计划里都可以关掉「计入本月预算」。预算外的钱照常扣账户余额、算进当月支出，但不占预算、不算进总结里的日均（适合买手机这种大额）
- **日历**：每天的收支、当月流水；点一条流水可以修改，左滑删除，余额自动跟着改
- **我的**：资金备忘、消费总结、消费标签、备份与清理
- **资金备忘**：记下「钱放在哪」，比如往 Apple 账号充了 $30 还没用。记账时这笔已经算支出了，备忘只是提醒，不影响任何金额；用完了可以标记「已用完」

## 文件结构

```
index.html        页面骨架，按顺序加载下面的脚本
css/style.css     全部样式
js/store.js       数据结构、读写 localStorage、旧数据迁移、小工具
js/calc.js        所有算钱的逻辑：余额、预算、预算外、总结统计
js/ui.js          通用零件：弹窗、提示、小输入框、选择药丸、左滑删除
js/home.js        首页 + 消费计划
js/record.js      记一笔面板 + 编辑流水
js/calendar.js    日历、流水列表、各标签折线图
js/popups.js      首页点数字弹出的面板（账户、安全余额、预算、专项）
js/summary.js     月度 / 年度总结
js/memo.js        资金备忘
js/settings.js    我的：标签、备份
js/app.js         页面切换、底部导航、快捷指令入口、启动
sw.js             离线缓存（有网时总是拿最新版）
manifest.json     添加到主屏幕用的配置
```

没有构建步骤，改完文件推到 main 分支，GitHub Pages 会自动部署（`.nojekyll` 让它原样发布文件）。
改了文件名或新增文件时，记得同步改 `sw.js` 里的 `ASSETS` 列表，并把 `CACHE` 的版本号加一。

## iOS 快捷指令记账

打开这个地址就会直接记一笔：

```
https://123sdgv.github.io/wallet/index.html?quickadd=expense&amount=12.5&note=午饭&account=微信&tag=伙食
```

| 参数 | 说明 |
| --- | --- |
| `quickadd` | `expense` 支出 / `income` 收入 |
| `amount` | 金额 |
| `note` | 备注，可不填 |
| `account` | 账户名称，不填用第一个账户 |
| `tag` | 标签名称（支出用），不填用「其他」 |
| `budget=0` | 记成预算外 |
